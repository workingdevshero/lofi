# Heroic LoFi for Vibe Coding

Working Dev's Hero album. Intended site: **https://lofi.workingdevshero.com**

Open `index.html` to listen and look.

**Read `PRODUCTION.md` before generating or submitting video.** Every track needs a **9:16 Short now** (YouTube via Automate It) **and** a **16:9 plate** banked for the long-form stitch later. Same audio under both. Do not publish 16:9 as a standalone YouTube video.

## Layout

- `characters/` — locked character boards
- `scenes/empty/` — approved empty plates (do not overwrite)
- `scenes/dressed/` — plates with cast painted in
- `scenes/archive/` — thrown-away stills we might want back
- `audio/` — Venice instrumental masters
- `videos/loops/` — Imagine idles
- `videos/masters/` — muxed loop + audio (`*-9x16.mp4` and `*-16x9.mp4`)
- `scripts/` — Venice queue/poll helpers

`characters/work/` is local scratch and is not in git.
